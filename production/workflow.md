# Production workflow

Target: under 3 hours per video, aim 2 hours. **All time targets below are unverified estimates.** Replace them with real numbers once there is data.

**Rule: log the actual time for every step in the "Actual" column, for every video.** Copy this table into the post's script file or keep one copy per post.

| # | Step | Target (estimate) | Actual |
|---|---|---|---|
| 1 | Pick idea and check duplication against the blocklist in `CLAUDE.md` | 45 min for steps 1-4 combined | |
| 2 | Research (WHY: source every fact; WHAT IF: mark fiction as fiction) | (in step 1 total) | |
| 3 | Write 3 hook options and pick one | (in step 1 total) | |
| 4 | Write script (narration table) | (in step 1 total) | |
| 5 | Storyboard (5-8 scenes, new scene every 3-5 s) | 15 min | |
| 6 | Record voice on phone | 15 min | |
| 7 | Build scenes in Remotion (3D + captions) | 45-60 min | |
| 8 | Review stills in Remotion Studio | 30 min for steps 8-9 combined | |
| 9 | Revise | (in step 8 total) | |
| 10 | Preflight checklist | 15 min for steps 10-12 combined | |
| 11 | Render final MP4 to `exports/final/` | (in step 10 total) | |
| 12 | Phone check (watch on a real phone, check captions and audio), then publish | (in step 10 total) | |

Total target: about 2 h 45 min to 3 h 0 min with the upper estimates.
